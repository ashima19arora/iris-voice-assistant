Run it on your own machine

Clone the repository and launch the Desktop Orb. It listens for a wake phrase or a right-click, and runs commands entirely on your own machine.

terminal
$ git clone https://github.com/ashima19arora/iris-voice-assistant.git
$ cd iris-voice-assistant
$ npm install
$ npm run orb
  • ✓No API keys required for core commands
  • ✓Global hotkey (Ctrl + Shift + Space) to summon Iris from anywhere
  • ✓First launch loads the speech model — 30 to 90 seconds, expected, not a bug.
